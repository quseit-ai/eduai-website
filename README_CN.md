# EduMate AI（教师教学智能体助手） — 软件发布说明

## 致各位老师

感谢您选择教师教学智能体助手。我们是一支专注于教育信息化的开发团队，深知备课、批改、学情分析、家校沟通占据了老师们大量的时间。为此，我们开发了这款专为教师教学工作设计的 AI 智能体助手，希望通过"自然语言对话 + 技能商店 + 数据连接"的方式，帮您把事务性、重复性的工作交给智能体，把时间还给教学本身。

本说明面向使用用户，介绍我们为您提供的功能、使用方法与注意事项。

## 一、我们能为您做什么

### 1. 帮您备课：从"零"到"可用教案"只需一句话

- **教案一键生成**：您只需告诉我"教学对象 + 课题 + 课时"，即可生成完整的教学设计，包含教学目标、成功标准、课堂导入、讲解环节、练习设计、检查理解与课堂小测，并自带分层设计。
- **分层教学材料**：同一节课，可自动生成"基础 / 达标 / 拔高"三档材料，方便您照顾不同水平的学生。
- **动态课件制作**：基于知识图谱生成可交互的 HTML 课件，支持课堂互动、语音播放，课件中的知识点图谱让学生一目了然。
- **教学设计打磨**：支持用 ADDIE 教学法对您的教学设计进行系统性审视与迭代优化，帮您把课磨得更细。

### 2. 帮您布置作业与测评：分层、可评分、可追溯

- **分层作业设计**：按"基础 60% / 标准 30% / 挑战 10%"生成分层作业，每道题标注建议用时，并自动配套教师答案版；您还可以把上次批改的错题数据发给我，我会据此设计更有针对性的下一次作业。
- **模拟卷与随堂测验**：根据知识点或大纲快速生成试卷，题型混合、难度分层，附完整答案解析。
- **评价量规（Rubric）**：为作业、项目、展示或写作任务一键建立清晰、可评分的量规。
- **作文批改反馈**：基于量规给出结构化批改意见，只指导、不代写，保护学生的独立思考。

### 3. 帮您做学情分析：不只看平均分，更看问题在哪

- **班级测验/错题数据分析**：您输入成绩分布和高频错题，我会按 C/P/R/Q（概念性 / 程序性 / 粗心 / 审题）四类进行错误归因，按"前置知识 + 错误率 + 分值权重"排出补救优先级，并给出每节课可落地的补教方案和可量化的检验指标——补没补到位，下一节课小测见分晓。

### 4. 帮您关注每一位学生：辅导资源随时可用

- 苏格拉底式辅导：通过引导式提问帮学生自己"想明白"，而不是直接给答案。
- 概念通俗讲解：用生活化类比讲透难懂概念，并即时检查学生是否真的懂了。
- 记忆卡片：把笔记/章节一键转成间隔重复闪卡（支持导入 Anki）。
- 考前心理疏导：为焦虑的学生提供安抚、分流与短期行动清单。
- 演讲演练、Python 启蒙、同伴冲突角色扮演等，覆盖学生成长的多种场景。

### 5. 帮您做好家校沟通：专业、温暖、不耗时

- **家长反馈报告**：一键生成家长会反馈和日常家校沟通消息，措辞专业、具体、有温度，让家长看见孩子的进步。

### 6. 帮您处理文档与日常办公

- **文档识别**：扫描件、照片、手写文档均可识别提取文字；PDF 支持直接编辑（改错字、改标题）。
- **Office 处理**：Word / Excel / PPT 的生成、编辑与批量处理，表格表单自动填写。
- **演示文稿**：从大纲到成稿的幻灯片一键生成。
- **邮件与日程**：收发邮件、管理日历、自动生成会议纪要。
- **笔记整理**：连接您的笔记库（如 Obsidian），帮您检索、整理、沉淀教学资料。

### 7. 帮您制作教学素材：图文、动画、音视频

- 教学信息图/海报：多种版式与风格，适合课堂展示与活动宣传。
- 数学/算法演示动画：3Blue1Brown 风格，适合讲抽象概念。
- 课件原型、AI 歌曲、ASCII 视频等创意素材，让课堂更有吸引力。

### 8. 数据连接与自动化（按贵校授权范围开放）

- **企业知识库**：可检索、保存学校内部文档资料（课程指南、规章制度等）。
- **业务数据库**：按权限查询与分析校内业务数据。
- **企业微信文档**：搜索、阅读、追加学校企业微信上的文档。
- **定时任务**：可设定周期性任务（如每日学情播报、资料监控、自动汇总），结果自动投递到您指定的渠道，您无需守着电脑。

## 二、技能商店：我们的持续更新，您的即插即用

我们内置了**技能商店**并持续上新。当前上架 **22 个技能**，教育类为主，安装后即插即用，无需任何编程基础：

- **备课类**：教案设计、分层教学、差异化教学、ADDIE 教学设计、动态课件制作；
- **作业测评类**：课堂学情分析、作业设计、模拟卷生成、评价量规、作文批改；
- **学生辅导类**：概念讲解、苏格拉底辅导、记忆闪卡、演讲演练、考试心理疏导、Python 启蒙、同伴冲突辅导；
- **办公类**：文档 OCR 识别、Office 表单填写；
- **通用类**：技能生成器。

**特别介绍"技能生成器"**：如果您希望把学校自己的作业模板、工作流程、教学 SOP 沉淀为专属技能，只需把流程和样例交给我们，即可一键生成校本专属技能，全校复用，形成属于贵校的数字资产。

## 三、如何使用

- 直接在对话框中用自然语言提出需求即可，例如：
  - "帮我设计一节 P4 分数的教案"
  - "根据上次测验的错题，设计一份分层作业"
  - "把这份扫描卷子转成可编辑 Word"
- 在技能商店中按需安装技能，安装后立即生效。
- 涉及学校数据的功能（知识库、数据库、企业微信）以管理员为您开通的权限为准。
